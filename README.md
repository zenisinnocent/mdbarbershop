# MD Barber Shop

A responsive, single-page website for **MD Barber Shop**, a premium grooming business. Customers can browse services, view the portfolio, add grooming products to a cart, and request appointments directly through WhatsApp.

## Features

- **Responsive design**: works on desktop, tablet and mobile
- **Sticky header** with smooth-scroll navigation
- **Services section**: Classic Haircut, Skin Fade, Beard Trim
- **Portfolio gallery** with hover effects and lazy-loaded images
- **Product shop** (Hair Clay, Beard Oil) with a cart counter saved in `localStorage`
